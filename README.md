# Pathfinder Visualizer

Pathfinder Visualizer is an interactive web application designed to help users understand pathfinding algorithms through visual representation.
Instead of simply reading about algorithms, users can watch them explore a grid step by step, compare their behavior, and understand how obstacles affect the pathfinding process.

This project combines algorithmic problem-solving with an interactive frontend to make graph traversal and pathfinding easier to understand.

## Features

- Interactive grid-based pathfinding visualization
- Visual representation of visited nodes
- Wall and obstacle placement
- Start and target node selection
- Animated pathfinding process
- Interactive user interface
- Responsive design
- Built with React and TypeScript

## Algorithms

The visualizer can be used to demonstrate pathfinding algorithms such as:

| Algorithm | Description |
|-----------|-------------|
| Breadth-First Search (BFS) | Explores nodes level by level and finds the shortest path in an unweighted grid. |
| Depth-First Search (DFS) | Explores as far as possible along a branch before backtracking. |
| Dijkstra's Algorithm | Finds the shortest path using the lowest known distance from the start node. |
| A* Search | Uses distance estimates to the target to guide the search efficiently. |

## How to Use

1. Open the Pathfinder Visualizer.
2. Select a pathfinding algorithm.
3. Create walls or obstacles on the grid.
4. Choose the start and target nodes, if supported.
5. Start the visualization.
6. Observe how the algorithm explores the grid.
7. Analyze the resulting path and visited nodes.
